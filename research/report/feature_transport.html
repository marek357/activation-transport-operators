Which features move between layers

We hill-climbed the linear maps between Gemma-2-2B residual layers (Szablewski & Masiak, arXiv:2508.17540). We then used them to say, feature by feature, what reaches a later layer: what is carried over, what is linearly assembled, and what the layers in between create.

Taxonomy of downstream features

Every Gemma Scope feature at the target layer that fires at least 20 times on the test split is put into one class, using held-out data only.

Matching features across layers

To say which upstream feature a downstream feature came from, prior work compares raw decoder directions. That assumes the residual stream does not rotate. We push upstream decoders through the learned operator first. We also try the operator's average Jacobian, a data-driven version of the Jacobian lens, and a CSLS hubness correction. The oracle is the partner with the highest activation correlation on the train split. The table shows how often each rule picks it on test.

Optimizing the feature metric directly

The paper's per-feature R² only scores tokens where a feature truly fires, so it cannot see a feature switched on where it should be off. Training the correction on that metric (a "feature loss" with weight λ) raises it quickly. The SAE code metrics show where that stops being real. At λ = 1 the transported vector reproduces the downstream SAE code better, with higher F1 and code FVE than the MSE-trained twin. At λ = 3 the paper's metric keeps rising while F1 and code FVE fall. Method, briefly

  • Data. The 251k-token SlimPajama activations released with the paper, with the repo's 60/20/20 split by sequence. All numbers are on the test split, excluding the <bos> position. Its residual is a constant vector about 12× the norm of a normal token, so we predict it by lookup.
  • Linear operator. ŷ = A·x + B·x̂ + b, with x̂ = x / rms(x). Gemma-2 sublayers read RMSNorm(x) and write through a post-norm, so the update depends on the direction of x. Ridge shrinks toward the identity, and α is chosen on validation.
  • Sparse correction. Wdec·topk64(ReLU(Wenc x̂)) with 8192 units, trained on the linear operator's residual. Neuron-like sparse units did as well as dense ones in our sweep, in line with work showing transcoder features are largely neurons in disguise.
  • Feature R². The R² of the projection onto a unit SAE decoder direction, over the tokens where that feature fires. This is the paper's metric, here applied to all active features instead of a curated 5%.
  • Explanations. Neuronpedia auto-interp labels, fetched per feature. Feature ids link to the Neuronpedia page.
